# Yilu Cao · Academic Website

A bilingual academic website for Yilu Cao (曹义路), built with HTML, CSS, and JavaScript. Hosted on GitHub Pages without a build step.

## Edit the website

- `index.html`: profile, research, education, honors, and contact information.
- `cv.html`: the public academic CV.
- `styles.css`: layout, responsive styles, and lightweight animations.
- `app.js`: language switch, research dialog, citation tools, reading progress, and entrance animations.
- `assets/`: self-hosted fonts and the frequency-wave illustration.

Push changes to the `main` branch to update GitHub Pages. Keep `.nojekyll` in the root of the publishing source.

The website respects `prefers-reduced-motion`; content remains accessible with JavaScript disabled. Fonts are distributed under the license in `assets/fonts/OFL.txt`.
